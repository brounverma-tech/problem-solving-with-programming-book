# 1.1 Introduction to Computers

## 1.1.1 Meaning of Computer

### 📘 English Definition

> A computer is an electronic programmable device that accepts data as input, processes it according to a set of instructions, stores it when required, and produces meaningful information as output.

### 💬 Hinglish Explanation

Computer ek **electronic machine** hai. Hum ise data aur instructions dete hain. Computer instructions ke अनुसार data ko process karta hai aur result deta hai.

**Computer** word Latin word **Computare** se bana hai, jiska meaning hai **to calculate**, yani calculation karna. Modern computer sirf calculation nahi karta. Yeh document banana, video chalana, internet use karna, banking, designing aur programming jaise bahut saare kaam karta hai.

### 🔄 Basic Working

```text
Input → Processing → Output → Storage
```

**Example:**

- Input: Student ke marks — 70, 80, 90
- Processing: Total aur percentage calculate karna
- Output: Total = 240, Percentage = 80%
- Storage: Result ko file ya database mein save karna

## 1.1.3 Data and Information

### 1.1.3.1 Data

> Data consists of raw and unorganized facts that may not have a clear meaning by themselves.

**Hinglish:** Data kacche facts hote hain. Jaise student ka naam, roll number aur alag-alag subjects ke marks.

**Examples:** `Broun`, `101`, `75`, `82`, `91`

### 1.1.3.2 Information

> Information is processed and organized data that is meaningful and useful.

**Hinglish:** Jab data ko process karke useful result banaya jata hai, use information kehte hain.

**Example:** “Student ka total 248 aur percentage 82.67% hai.”

### 1.1.3.3 Difference Between Data and Information

| Basis | Data | Information |
|---|---|---|
| Nature | Raw facts | Processed facts |
| Meaning | Akela meaningful nahi ho sakta | Meaningful hota hai |
| Role | Input ke roop mein use hota hai | Output ke roop mein milta hai |
| Example | 70, 80, 90 | Average = 80 |

# 1.2 Characteristics of Computers

## 1.2.1 Speed

Computer bahut high speed se calculations aur instructions perform karta hai. Iski speed ko milliseconds, microseconds, nanoseconds aur picoseconds mein measure kiya ja sakta hai.

| Unit | Symbol | Time |
|---|---:|---:|
| Millisecond | ms | $10^{-3}$ second |
| Microsecond | μs | $10^{-6}$ second |
| Nanosecond | ns | $10^{-9}$ second |
| Picosecond | ps | $10^{-12}$ second |

> 💡 **Example:** Computer kuch seconds mein hazaron students ka result calculate kar sakta hai.

## 1.2.2 Accuracy

Computer correct data aur correct instructions milne par highly accurate result deta hai.

### 1.2.2.1 GIGO

**GIGO** ka full form hai **Garbage In, Garbage Out**.

Agar input ya program galat hai, to output bhi galat hoga. Ismein गलती computer ki nahi, diye gaye data ya instruction ki hoti hai.

## 1.2.3 Automation

Program start hone ke baad computer instructions ko automatically execute kar sakta hai. Har step par human intervention ki zarurat nahi hoti.

## 1.2.4 Diligence

**Diligence (डिलिजेन्स)** ka meaning hai bina thake aur bina bore hue लगातार kaam karna. Computer same task ko baar-baar same speed aur accuracy se perform kar sakta hai.

## 1.2.5 Storage Capacity

Computer large amount of data ko store kar sakta hai aur zarurat padne par quickly retrieve kar sakta hai.

## 1.2.6 Versatility

**Versatility (वर्सटिलिटी)** ka meaning hai alag-alag types ke kaam karne ki ability. Ek computer se coding, designing, banking, education aur entertainment sab kiya ja sakta hai.

## 1.2.7 Reliability

Computer same input aur instructions par consistent result deta hai. Proper maintenance ke saath yeh long time tak reliable tarike se kaam karta hai.

## 1.2.8 Multitasking

Computer ek hi samay par multiple tasks handle kar sakta hai, jaise music play karna, file download karna aur document edit karna.

## 1.2.9 No Intelligence of Its Own

Computer ke paas apni natural intelligence ya common sense nahi hota. Yeh user aur program ke instructions ke अनुसार kaam karta hai.

## 1.2.10 No Feelings

Computer ke paas emotions, likes, dislikes aur personal judgement nahi hote.

# 1.3 Evolution of Computers

## 1.3.1 Meaning of Evolution

> Evolution of computers means the gradual development of calculating devices into modern electronic computers.

**Hinglish:** Simple counting tools se lekar powerful digital machines tak computer technology ke step-by-step development ko computer evolution kehte hain.

## 1.3.2 Important Early Computing Devices

| Device/Machine | Person | Approx. Year | Main Contribution |
|---|---|---:|---|
| Abacus | Unknown | Ancient period | Basic counting |
| Pascaline | Blaise Pascal | 1642 | Addition and subtraction |
| Stepped Reckoner | Gottfried Leibniz | 1673 | Basic arithmetic operations |
| Difference Engine | Charles Babbage | 1822 | Automatic mathematical tables |
| Analytical Engine | Charles Babbage | 1837 | General-purpose computer concept |
| Tabulating Machine | Herman Hollerith | 1890 | Punched-card data processing |
| Mark I | Howard Aiken and IBM | 1944 | Electromechanical calculation |
| ENIAC | Eckert and Mauchly | 1946 | Early general-purpose electronic computer |
| EDVAC | Eckert, Mauchly and von Neumann team | 1949 | Stored-program concept |
| UNIVAC I | Eckert and Mauchly | 1951 | Early commercial computer |

> 👨‍💻 **Charles Babbage** ko generally **Father of Computer** kaha jata hai.  
> 👩‍💻 **Ada Lovelace** ko generally **First Computer Programmer** maana jata hai.

# 1.4 Generations of Computers

## 1.4.1 Meaning of Computer Generation

Computer generation technology ke ek major development stage ko represent karti hai. Har generation mein hardware, software, size, speed, storage aur reliability improve hui.

## 1.4.2 First Generation Computers

### 1.4.2.1 Period
Approximately **1940–1956**

### 1.4.2.2 Main Technology
**Vacuum tubes**

### 1.4.2.3 Features
- Size bahut bada tha.
- Electricity consumption bahut zyada tha.
- Bahut heat generate hoti thi.
- Machine language use hoti thi.
- Punched cards input ke liye use hote the.
- Maintenance costly thi.

### 1.4.2.4 Examples
ENIAC, EDVAC, EDSAC, UNIVAC I, IBM 701

## 1.4.3 Second Generation Computers

### 1.4.3.1 Period
Approximately **1956–1963**

### 1.4.3.2 Main Technology
**Transistors**

### 1.4.3.3 Features
- First generation se smaller aur faster.
- Less heat aur lower power consumption.
- More reliable.
- Assembly language aur early high-level languages ka use.
- Magnetic core memory ka use.

### 1.4.3.4 Examples
IBM 1401, IBM 7094, CDC 1604, UNIVAC 1108

## 1.4.4 Third Generation Computers

### 1.4.4.1 Period
Approximately **1964–1971**

### 1.4.4.2 Main Technology
**Integrated Circuits (ICs)**

### 1.4.4.3 Features
- Multiple electronic components ek chip par.
- Size aur cost kam hui.
- Speed aur reliability badhi.
- Operating systems aur multiprogramming ka development.
- Keyboard aur monitor ka use popular hua.

### 1.4.4.4 Examples
IBM System/360, PDP-8, PDP-11

## 1.4.5 Fourth Generation Computers

### 1.4.5.1 Period
Approximately **1971–Present**

### 1.4.5.2 Main Technology
**Microprocessor, LSI and VLSI**

### 1.4.5.3 Features
- CPU ek microprocessor chip par available hua.
- Personal computers ka development.
- Small size, high speed aur large storage.
- GUI, networking aur portable computers popular hue.
- Cost kam hui aur common users tak computers pahunche.

### 1.4.5.4 Examples
IBM PC, Apple Macintosh, modern desktops and laptops

## 1.4.6 Fifth Generation Computers

### 1.4.6.1 Period
Present and future-oriented development

### 1.4.6.2 Main Technology
**ULSI, Artificial Intelligence and parallel processing**

### 1.4.6.3 Features
- Artificial Intelligence based systems.
- Natural language processing.
- Machine learning and robotics.
- Very high processing speed.
- Large memory and cloud connectivity.

### 1.4.6.4 Examples
AI-enabled systems, robots, expert systems and modern supercomputers

## 1.4.7 Generation Comparison

| Generation | Main Technology | Size | Speed | Common Language/Input |
|---|---|---|---|---|
| First | Vacuum tubes | Very large | Milliseconds | Machine language, punch cards |
| Second | Transistors | Smaller | Microseconds | Assembly, FORTRAN, COBOL |
| Third | ICs | Medium/small | Nanoseconds | High-level languages |
| Fourth | Microprocessors | Very small | Very high | GUI and modern languages |
| Fifth | AI, ULSI | Compact | Extremely high | Natural language and AI tools |

# 1.5 Classification of Computers

## 1.5.1 Classification by Data Handling

### 1.5.1.1 Analog Computer

Analog computer continuous physical quantities ko process karta hai.

**Examples:** Traditional speedometer, analog thermometer, process-control systems.

### 1.5.1.2 Digital Computer

Digital computer discrete values, mainly binary digits `0` and `1`, par kaam karta hai.

**Examples:** Desktop, laptop, smartphone, calculator.

### 1.5.1.3 Hybrid Computer

Hybrid computer analog aur digital computer dono ki features combine karta hai.

**Examples:** ICU monitoring system, petrol pump measurement system, scientific control systems.

## 1.5.2 Classification by Purpose

### 1.5.2.1 General-Purpose Computer

Different types ke tasks ke liye use hota hai.

**Examples:** Desktop, laptop, smartphone.

### 1.5.2.2 Special-Purpose Computer

Ek specific task ke liye design hota hai.

**Examples:** ATM controller, traffic-light controller, washing-machine controller.

## 1.5.3 Classification by Size and Processing Power

### 1.5.3.1 Microcomputer

Single user ke daily tasks ke liye designed small computer.

**Examples:** Desktop, laptop, tablet, smartphone.

### 1.5.3.2 Minicomputer

Microcomputer se powerful multi-user system. Aaj is category ke bahut se roles mid-range servers perform karte hain.

### 1.5.3.3 Mainframe Computer

Large organizations mein huge data aur many simultaneous users ko handle karta hai.

**Examples:** Banking, railway reservation and government records.

### 1.5.3.4 Supercomputer

Most complex scientific calculations ke liye extremely powerful computer.

**Applications:** Weather forecasting, space research, simulations and climate modelling.

# 1.6 Basic Computer Organization

## 1.6.1 Input Unit

User se data aur instructions receive karti hai.

**Examples:** Keyboard, mouse, scanner, microphone.

## 1.6.2 Central Processing Unit

CPU ko computer ka **brain** kaha jata hai.

### 1.6.2.1 Arithmetic Logic Unit

ALU arithmetic calculations aur logical comparisons perform karta hai.

- Arithmetic: Addition, subtraction, multiplication, division
- Logical: Greater than, less than, equal to

### 1.6.2.2 Control Unit

Control Unit computer ke different components ke operations ko control aur coordinate karti hai.

### 1.6.2.3 Registers

Registers CPU ke andar present very fast temporary storage locations hote hain.

## 1.6.3 Memory and Storage Unit

Data, instructions aur results ko temporarily ya permanently store karti hai.

- **Primary memory:** RAM, ROM
- **Secondary storage:** HDD, SSD, pen drive, memory card

## 1.6.4 Output Unit

Processed result ko user ke understandable form mein present karti hai.

**Examples:** Monitor, printer, speaker, projector.

## 1.6.5 IPO Cycle

| Stage | Work | Example |
|---|---|---|
| Input | Data enter karna | Keyboard se marks |
| Process | Calculation karna | Total and percentage |
| Output | Result show karna | Monitor par result |
| Storage | Result save karna | SSD/database mein save |

# 1.8 Advantages and Limitations

## 1.8.1 Advantages

- High speed
- High accuracy
- Large storage
- Automation
- Reliability
- Multitasking
- Easy communication

## 1.8.2 Limitations

- Wrong input par wrong output milta hai.

# 1.9 Chapter Summary

Is chapter mein humne computer ki basic foundation samjhi. Computer ek electronic aur programmable device hai jo data ko input ke roop mein leta hai, instructions ke according process karta hai aur meaningful information output ke roop mein deta hai. Iski working ko Input–Process–Output–Storage cycle se samjha ja sakta hai.

Computer ki main characteristics speed, accuracy, automation, diligence, storage capacity, versatility, reliability aur multitasking hain. Computer apne aap decision nahi leta; yeh program aur user ke instructions par depend karta hai. Galat input se galat output milne ke principle ko GIGO kehte hain.

Computer technology simple calculating devices se develop hokar modern systems tak pahunchi. Five generations mein vacuum tubes, transistors, integrated circuits, microprocessors aur AI-oriented technologies ka development hua. Computers ko data handling ke आधार पर analog, digital aur hybrid; purpose ke आधार पर general-purpose aur special-purpose; aur processing power ke आधार पर microcomputer, minicomputer, mainframe aur supercomputer mein classify kiya jata hai.

Basic computer organization mein input unit, CPU, memory/storage unit aur output unit shamil hain. CPU ke main parts ALU, Control Unit aur registers hain. Aaj computers education, banking, healthcare, business, science, communication, transport, entertainment aur security jaise lagbhag har field mein use hote hain.
