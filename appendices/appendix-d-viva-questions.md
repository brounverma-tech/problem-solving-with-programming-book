## D.1 Computer Fundamentals

### D.1.1 Computer kya hai?

Computer ek electronic device hai jo input data ko instructions ke according process karke meaningful output deta hai.

### D.1.2 Computer ke main functional units kaun se hain?

Input Unit, Memory Unit, Central Processing Unit aur Output Unit computer ke main functional units hain.

### D.1.3 Data aur information me kya difference hai?

Data raw facts hote hain, jabki processed aur meaningful data ko information kehte hain.

### D.1.4 Hardware kya hota hai?

Computer ke physical parts jinhe dekha aur chhua ja sakta hai, hardware kehlate hain. Jaise keyboard, monitor aur CPU.

### D.1.5 Software kya hota hai?

Software instructions aur programs ka collection hai jo computer ko batata hai ki kaam kaise karna hai.

### D.1.6 CPU ko computer ka brain kyon kehte hain?

CPU instructions execute karta hai, calculations karta hai aur computer ke dusre parts ko control karta hai.

### D.1.7 ALU ka kya kaam hai?

Arithmetic Logic Unit mathematical calculations aur logical comparisons perform karta hai.

### D.1.8 Control Unit ka kya kaam hai?

Control Unit instructions ko interpret karke computer ke different units ki activities coordinate karta hai.

---

## D.2 Memory and Storage

### D.2.1 Primary memory kya hai?

Primary memory CPU ke directly accessible memory area ko kehte hain. RAM aur ROM iske main examples hain.

### D.2.2 RAM aur ROM me kya antar hai?

RAM temporary aur volatile memory hai. ROM permanent aur non-volatile memory hoti hai.

### D.2.3 Volatile memory kya hoti hai?

Aisi memory jiska data power off hone par delete ho jata hai, volatile memory kehlati hai.

### D.2.4 Cache memory kya hai?

Cache ek small aur high-speed memory hai jo frequently used data aur instructions ko CPU ke paas store karti hai.

### D.2.5 Secondary storage kya hai?

Long-term data storage ke liye use hone wali non-volatile memory secondary storage kehlati hai. Jaise SSD aur hard disk.

### D.2.6 Bit aur byte me kya relation hai?

Bit data ki smallest unit hai. Eight bits milkar one byte banate hain.

### D.2.7 Register kya hota hai?

Register CPU ke andar present very small aur fastest storage location hota hai.

---

## D.3 Input and Output Devices

### D.3.1 Input device kya hai?

Jis device se computer ko data ya instructions diye jaate hain, use input device kehte hain.

### D.3.2 Output device kya hai?

Jis device se processed result user ko milta hai, use output device kehte hain.

### D.3.3 Scanner ka kya use hai?

Scanner paper par present text ya image ko digital form me convert karta hai.

### D.3.4 Soft copy aur hard copy kya hain?

Screen par available electronic output soft copy hai. Printed output hard copy kehlata hai.

### D.3.5 Impact aur non-impact printer me kya difference hai?

Impact printer paper par mechanical strike karta hai. Non-impact printer bina strike kiye printing karta hai.

---

## D.4 Software and Internet

### D.4.1 System software kya hai?

System software computer hardware ko operate aur manage karta hai. Operating system iska main example hai.

### D.4.2 Application software kya hai?

User ke specific task ko perform karne wala software application software kehlata hai. Jaise MS Word.

### D.4.3 Operating system kya hai?

Operating system user, applications aur computer hardware ke beech interface ka kaam karta hai.

### D.4.4 Compiler aur interpreter me kya difference hai?

Compiler complete program ko ek saath translate karta hai. Interpreter instructions ko line-by-line translate aur execute karta hai.

### D.4.5 Internet kya hai?

Internet interconnected computer networks ka worldwide network hai.

### D.4.6 WWW kya hai?

World Wide Web internet par available interlinked web pages aur resources ka collection hai.

### D.4.7 Browser aur search engine me kya difference hai?

Browser websites access karne ka software hai. Search engine internet par information search karne ki online service hai.

### D.4.8 URL kya hai?

Uniform Resource Locator internet par kisi resource ka unique address hota hai.

---

## D.5 Number Systems and Computer Codes

### D.5.1 Number system kya hai?

Numbers ko represent karne ke rules aur symbols ke set ko number system kehte hain.

### D.5.2 Binary number system ka base kya hai?

Binary ka base `2` hai aur isme sirf `0` aur `1` digits use hote hain.

### D.5.3 Octal aur hexadecimal ke bases kya hain?

Octal ka base `8` aur hexadecimal ka base `16` hota hai.

### D.5.4 Decimal `10` ka binary form kya hai?

Decimal `10` ka binary form `1010` hai.

### D.5.5 ASCII kya hai?

ASCII characters ko numeric codes ke through represent karne ka standard encoding system hai.

### D.5.6 Unicode ki zarurat kyon padi?

Unicode duniya ki multiple languages aur symbols ko ek common encoding system me represent karta hai.

## D.6 C++ Fundamentals

### D.6.1 C++ kya hai?

C++ ek general-purpose, compiled aur multi-paradigm programming language hai.

### D.6.2 C++ ko kisne develop kiya?

C++ ko Bjarne Stroustrup ne Bell Laboratories me develop kiya.

### D.6.3 C aur C++ me basic difference kya hai?

C mainly procedural language hai, jabki C++ procedural programming ke saath object-oriented features bhi support karti hai.

### D.6.4 `main()` function ka kya purpose hai?

C++ program ka execution `main()` function se start hota hai.

### D.6.5 Header file kya hoti hai?

Header file declarations aur reusable library features provide karti hai. Jaise `<iostream>` input-output ke liye use hoti hai.

### D.6.6 `using namespace std;` ka kya purpose hai?

Isse standard library ke names ke saath baar-baar `std::` likhne ki zarurat nahi padti.

### D.6.7 Identifier kya hai?

Program me variable, function, class ya kisi dusre element ko diya gaya naam identifier hota hai.

### D.6.8 Keyword kya hai?

Keyword language ka reserved word hota hai jiska predefined meaning hota hai. Jaise `int`, `if` aur `return`.

### D.6.9 Variable aur constant me kya difference hai?

Variable ki value program ke dauran change ho sakti hai. Constant ki value declaration ke baad change nahi hoti.

### D.6.10 C++ case-sensitive hai—iska kya matlab hai?

Uppercase aur lowercase letters alag maane jaate hain. Isliye `total` aur `Total` different identifiers hain.

---

## D.7 Data Types and Operators

### D.7.1 Data type kya batata hai?

Data type batata hai ki variable kis type ki value store karega aur us par kaun se operations valid hain.

### D.7.2 Fundamental data types ke examples kya hain?

`int`, `char`, `float`, `double`, `bool` aur `void` fundamental data types hain.

### D.7.3 Type casting kya hai?

Ek data type ki value ko dusre data type me convert karna type casting kehlata hai.

### D.7.4 Assignment aur equality operators me kya difference hai?

`=` value assign karta hai, jabki `==` do values ki equality check karta hai.

### D.7.5 Modulus operator ka kya use hai?

`%` integer division ka remainder return karta hai.

### D.7.6 Pre-increment aur post-increment me kya difference hai?

`++x` pehle value increase karta hai, jabki `x++` expression me purani value use karne ke baad increase karta hai.

### D.7.7 Operator precedence kya hai?

Operator precedence decide karti hai ki expression me kaunsa operator pehle evaluate hoga.

---

## D.8 Decision-Making and Loops

### D.8.1 `if` statement kab use hota hai?

Jab kisi condition ke true hone par code execute karna ho tab `if` statement use hota hai.

### D.8.2 `switch` statement ki limitation kya hai?

`switch` discrete constant values ke saath kaam karta hai; ranges aur complex logical conditions directly handle nahi karta.

### D.8.3 `for` aur `while` loop me kya difference hai?

Known iterations ke liye `for` convenient hai. Condition-based unknown iterations ke liye `while` useful hai.

### D.8.4 `while` aur `do-while` me kya difference hai?

`while` condition pehle check karta hai. `do-while` body pehle execute karta hai, isliye woh minimum ek baar chalta hai.

### D.8.5 Infinite loop kya hai?

Aisa loop jiski termination condition kabhi false nahi hoti, infinite loop kehlata hai.

### D.8.6 `break` aur `continue` me kya difference hai?

`break` loop ko terminate karta hai. `continue` sirf current iteration ko skip karta hai.

---

## D.9 Functions

### D.9.1 Function kya hai?

Function code ka reusable block hai jo ek specific task perform karta hai.

### D.9.2 Function prototype kya hai?

Function prototype compiler ko function ka name, return type aur parameters execution se pehle batata hai.

### D.9.3 Actual aur formal parameters kya hain?

Function call me di gayi values actual parameters hain. Function definition me receive karne wale variables formal parameters hain.

### D.9.4 Call by value kya hai?

Call by value me argument ki copy function ko milti hai, isliye original variable normally change nahi hota.

### D.9.5 Call by reference kya hai?

Call by reference me original variable ka reference pass hota hai, isliye function uski actual value modify kar sakta hai.

### D.9.6 Recursion kya hai?

Jab function khud ko call karta hai to use recursion kehte hain. Recursion me base condition zaruri hoti hai.

### D.9.7 Function overloading kya hai?

Same name ke multiple functions ko different parameter lists ke saath define karna function overloading hai.

---

## D.10 Arrays and Strings

### D.10.1 Array kya hai?

Array same data type ke multiple elements ko contiguous memory locations me store karta hai.

### D.10.2 Array indexing kahan se start hoti hai?

C++ me array indexing `0` se start hoti hai.

### D.10.3 One-dimensional aur two-dimensional array me kya difference hai?

One-dimensional array list ki tarah hota hai. Two-dimensional array rows aur columns wali table ya matrix ki tarah hota hai.

### D.10.4 Array bounds ke bahar access karne par kya hota hai?

Yeh undefined behavior hai aur wrong result, crash ya memory corruption cause kar sakta hai.

### D.10.5 C-style string aur `string` me kya difference hai?

C-style string null character se end hone wala character array hai. `string` standard library ki convenient class hai.

### D.10.6 Linear search kya hai?

Linear search elements ko start se ek-ek karke target value ke saath compare karta hai.

### D.10.7 Bubble sort kaise kaam karta hai?

Bubble sort adjacent elements compare karke wrong order me hone par swap karta hai. Yeh process multiple passes tak chalta hai.

---

## D.11 Pointers

### D.11.1 Pointer kya hai?

Pointer ek variable hai jo kisi dusre variable ka memory address store karta hai.

### D.11.2 Address operator kya hai?

`&` operator kisi variable ka memory address return karta hai.

### D.11.3 Dereference operator kya hai?

`*` operator pointer me stored address par present value ko access karta hai.

### D.11.4 Null pointer kya hai?

Aisa pointer jo kisi valid object ko point nahi karta, null pointer kehlata hai. Modern C++ me `nullptr` use kiya jata hai.

### D.11.5 Dangling pointer kya hai?

Aisa pointer jo delete ya invalid ho chuki memory ko point karta rahe, dangling pointer kehlata hai.

### D.11.6 Pointer arithmetic kya hai?

Pointer par increment, decrement ya offset operations karke adjacent elements ke addresses access karna pointer arithmetic hai.

### D.11.7 `new` aur `delete` ka kya use hai?

`new` runtime par dynamic memory allocate karta hai aur `delete` allocated memory ko release karta hai.

### D.11.8 Memory leak kya hai?

Allocated dynamic memory ko release na karne aur uska usable reference kho dene ko memory leak kehte hain.

## D.12 Common Practical Viva Questions

### D.12.1 Program compile nahi ho raha ho to sabse pehle kya check karenge?

Compiler error message, missing semicolon, brackets, spelling, header files aur variable declarations check karenge.

### D.12.2 Syntax error kya hai?

Programming language ke grammar rules break hone par syntax error aata hai.

### D.12.3 Runtime error kya hai?

Program execution ke samay aane wali error runtime error hai. Jaise invalid memory access.

### D.12.4 Logical error kya hai?

Program successfully run hota hai lekin incorrect logic ki wajah se wrong output deta hai.

### D.12.5 Debugging kya hai?

Program me errors ko identify, analyze aur correct karne ki process debugging kehlati hai.

### D.12.6 Algorithm kya hai?

Problem solve karne ke finite aur ordered steps ko algorithm kehte hain.

### D.12.7 Flowchart kya hai?

Algorithm ya process ka graphical representation flowchart kehlata hai.

### D.12.8 Dry run kya hota hai?

Program ko manually step-by-step trace karke variables aur output verify karna dry run hai.

## ✅ Viva Preparation Tips

- Definition ke saath ek simple example ya use bhi batayein.
- Answer short aur direct rakhein.
- Code explain karte samay input, process aur output ka order follow karein.
- `=` versus `==`, call by value versus reference aur RAM versus ROM jaise differences revise karein.
- Practical program ki har important line ka purpose samjhein.
- Agar exact answer yaad na ho to concept ko apne words me clearly explain karein.
