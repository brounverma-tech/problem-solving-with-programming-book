## G.1 A–C

| Term | Easy Meaning |
|---|---|
| **Algorithm** | Problem solve karne ke finite aur step-by-step instructions. |
| **ALU** | CPU ka part jo arithmetic aur logical operations perform karta hai. |
| **Application Software** | User ke specific tasks ke liye bana software, jaise word processor. |
| **Argument** | Function call ke samay function ko di gayi value. |
| **Array** | Same data type ke multiple elements ka ordered collection. |
| **ASCII** | Characters ko numeric codes me represent karne ka encoding standard. |
| **Assembler** | Assembly language ko machine code me translate karne wala software. |
| **Binary** | Base-2 number system jo `0` aur `1` use karta hai. |
| **Bit** | Computer data ki smallest unit; value `0` ya `1`. |
| **Browser** | Websites access aur display karne wala software. |
| **Bug** | Program me present error ya defect. |
| **Byte** | Eight bits ka group. |
| **Cache Memory** | CPU ke paas present small aur high-speed memory. |
| **Call by Reference** | Function ko original variable ka reference pass karne ka method. |
| **Call by Value** | Function ko argument ki copy pass karne ka method. |
| **Character** | Letter, digit ya special symbol ki single unit. |
| **Class** | Objects create karne ka user-defined blueprint. |
| **Cloud Computing** | Internet ke through computing resources aur services use karna. |
| **Code** | Programming language me likhe gaye instructions. |
| **Compiler** | Complete source program ko machine-level form me translate karta hai. |
| **Constant** | Aisi named value jo program execution ke dauran change nahi hoti. |
| **Control Unit** | CPU ka part jo instructions aur system operations coordinate karta hai. |
| **CPU** | Central Processing Unit; instructions execute karne wala main processor. |

## G.10 Frequently Confused Terms

| Term 1 | Term 2 | Main Difference |
|---|---|---|
| Data | Information | Data raw hai; information processed aur meaningful hai. |
| RAM | ROM | RAM volatile aur writable hai; ROM non-volatile hai. |
| Compiler | Interpreter | Compiler complete program; interpreter line-by-line translate karta hai. |
| Internet | WWW | Internet network infrastructure; WWW us par available web service hai. |
| Browser | Search Engine | Browser software; search engine online search service hai. |
| Variable | Constant | Variable change ho sakta hai; constant fixed rehta hai. |
| `=` | `==` | `=` assignment; `==` equality comparison hai. |
| Argument | Parameter | Argument call me diya jata hai; parameter function definition me receive karta hai. |
| Array | Pointer | Array elements ka collection; pointer memory address store karta hai. |
| Null Pointer | Dangling Pointer | Null kisi valid object ko point nahi karta; dangling invalidated memory ko point karta hai. |
