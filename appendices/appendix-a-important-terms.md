|---|---|---|---|
| Computer | कम्प्यूटर | Electronic programmable data-processing device | Data input lekar process aur output dene wali machine |
| Data | डेटा | Raw facts and figures | Kacche facts, jaise marks ya names |
| Information | इन्फॉर्मेशन | Processed meaningful data | Processed aur useful data |
| Hardware | हार्डवेयर | Physical computer components | Computer ke touch kiye ja sakne wale parts |
| Software | सॉफ्टवेयर | Programs and instructions | Hardware ko kaam batane wale programs |
| Program | प्रोग्राम | Ordered set of instructions | Task perform karne wali instructions |
| Input | इनपुट | Data supplied to a computer | Computer ko diya gaya data |
| Output | आउटपुट | Processed result | Computer se mila result |
| Processing | प्रोसेसिंग | Operations performed on data | Data par calculation ya operation |
| Storage | स्टोरेज | Facility for retaining data | Data save rakhne ki jagah |
| Automation | ऑटोमेशन | Automatic operation after instructions | Instructions ke baad automatic kaam |
| Accuracy | एक्युरेसी | Correctness of results | Result kitna correct hai |
| Diligence | डिलिजेन्स | Ability to work without fatigue | Bina thake repeated work |
| Versatility | वर्सटिलिटी | Ability to perform different tasks | Different types ke kaam karne ki ability |
| GIGO | गिगो | Garbage In, Garbage Out | Galat input se galat output |

# A.2 Memory and Processor Terms

| Term | Pronunciation | English Meaning | Easy Hinglish Explanation |
|---|---|---|---|
| Bit | बिट | Binary digit, 0 or 1 | Memory ki smallest binary unit |
| Byte | बाइट | Group of eight bits | 8 bits ka group |
| Memory | मेमोरी | Storage for data and instructions | Data aur instructions rakhne ki jagah |
| Volatile | वॉलटाइल | Loses data without power | Power off par data lost |
| Non-volatile | नॉन-वॉलटाइल | Retains data without power | Power off par bhi data saved |
| RAM | रैम | Volatile main memory | Running programs ki temporary memory |
| ROM | रोम | Non-volatile read-oriented memory | Firmware/startup instructions ki memory |
| Cache | कैश | Small high-speed memory near CPU | Frequently used data ki fast memory |
| Register | रजिस्टर | Very fast CPU storage location | CPU ke andar smallest fast storage |
| Processor | प्रोसेसर | Component that executes instructions | Instructions execute karne wala component |
| CPU | सीपीयू | Central Processing Unit | Computer ka main processing unit |
| ALU | एएलयू | Arithmetic Logic Unit | Calculations aur comparisons karta hai |
| Control Unit | कंट्रोल यूनिट | Coordinates computer operations | Components ke kaam ko control karti hai |
| Clock Speed | क्लॉक स्पीड | Processor cycles per second | CPU timing ki rate |
| Bus | बस | Signal-transfer path | Components ke beech data/signal path |
| HDD | एचडीडी | Magnetic hard disk drive | Magnetic long-term storage |
| SSD | एसएसडी | Flash-based solid-state drive | Fast storage without moving parts |

# A.8 Functions, Arrays and Pointers Terms

| Term | Pronunciation | English Meaning | Easy Hinglish Explanation |
|---|---|---|---|
| Function | फंक्शन | Reusable named code block | Specific task ka reusable block |
| Parameter | पैरामीटर | Input variable in function definition | Function mein input receive karta hai |
| Argument | आर्ग्यूमेंट | Value supplied in a function call | Call ke time supplied value |
| Return Value | रिटर्न वैल्यू | Value sent back by a function | Function se caller ko mila result |
| Scope | स्कोप | Region where a name is visible | Name kahan accessible hai |
| Overloading | ओवरलोडिंग | Same name with different parameter lists | Same function name ke multiple forms |
| Array | अरे | Fixed same-type element collection | Same type ki multiple indexed values |
| Index | इंडेक्स | Element position | Array element ka position number |
| Traversal | ट्रैवर्सल | Visiting all elements | Array ke elements one-by-one process karna |
| Linear Search | लिनियर सर्च | Sequential search | Elements ko one-by-one search karna |
| Pointer | पॉइंटर | Variable storing an address | Memory address store karne wala variable |
| Dereference | डीरेफरेंस | Accessing pointed value | Pointer ke address par value access karna |
| nullptr | नल पॉइंटर | Pointer value representing no object | Kisi valid object ko point nahi karta |
| Dangling Pointer | डैंगलिंग पॉइंटर | Pointer to invalid lifetime-ended object | Deleted/destroyed memory ka old address |
| Memory Leak | मेमोरी लीक | Allocated memory not released | Dynamic memory release na hona |
| Heap | हीप | Dynamic-storage region | Runtime allocations ki memory area |
| Smart Pointer | स्मार्ट पॉइंटर | Automatic ownership-managing object | Memory/resource automatically manage karta hai |
| Command-Line Argument | कमांड-लाइन आर्ग्यूमेंट | Value supplied when starting a program | Program run karte time diya gaya input |
